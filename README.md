# 🚌 Nielsen Product Design Internship — The Conductor's Digital Companion

## Project Context
- **Company**: The Nielsen Company (US), LLC
- **Role**: Product Design Intern
- **Assignment**: Brief 1 — Digitize the thermal-printer ETM machine used by bus conductors (BMTC/BEST)
- **Deadline**: 12 Oct 2026
- **Submission Format**: Google Slides deck + Live interactive HTML prototype

## Core Constraints (from brief)
1. **One-Handed Use** — Conductor is in a jerky bus, holding cash in one hand, phone in the other
2. **Speed** — Select destination + issue ticket for 3 passengers in **under 4 seconds**
3. **Visibility** — Must be "glanceable" in high-glare, high-frequency environments

## Deliverables
1. High-fidelity UI of the ticketing flow
2. Breakdown of navigation/reachability strategy
3. Interactive HTML prototype (our differentiator)
4. Google Slides narrative deck
